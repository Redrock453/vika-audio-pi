# Vika Audio Pi

**Автономный безэкранный аудиоплеер и голосовой терминал на Raspberry Pi 3 Model A+ (512 МБ).**

Слушать аудиокниги, музыку и лекции **без телефона, монитора и постоянного интернета**. Воспроизведение и базовое управление работают локально; Bluetooth-наушники, проводной аудиовыход, кнопки и офлайн-голосовые подсказки — поэтапно.

**Статус:** требования и исследование решений, 2026-11-23. Подготовлен staged-пакет MPD + USB
(не запускался на Pi; установка требует интерактивного sudo). Это *не готовый продукт*.
Никаких секретов Wi-Fi, паролей, SSH-ключей или дампов устройства в репозитории нет.

## Аппаратная база

- Raspberry Pi 3 Model A+, 512 МБ RAM, 64-ГБ microSD.
- Raspberry Pi OS Lite **32-bit Trixie (Raspbian 13)**, без графического интерфейса.
- Wi-Fi уже работает; SSH по ключу доступен с доверенного T450.
- Bluetooth-гарнитура обнаруживалась как **HD-610** (соединение и звук ещё не приняты).
- Есть **вторая, проводная гарнитура JBL с кнопкой**; звук через 3,5 мм Pi возможен, но штатный разъём **не принимает микрофон и не распознаёт кнопку**. Их использование требует отдельного проверенного интерфейса.

## Приоритеты

1. Стабильный офлайн-плеер, сохранение позиции аудиокниг, управление без телефона.
2. Надёжное подключение Bluetooth и проводной запасной аудиовыход.
3. Голосовые уведомления, навигация по библиотеке, таймер сна.
4. Офлайн-команды с **отдельным проверенным микрофоном**; тяжёлые ИИ-модели на Pi не размещать.

## Принцип

**«Детерминированный скелет, ИИ только в суставах».**

Медиаплеер, права доступа, очередь и сохранение позиции — обычный код; распознавание команд необязательно для работы. Позднее устройство может стать периферийным узлом Вики, но **не зависит** от `vika_relay`, облака или смартфона.

## Границы

Старая 32-ГБ microSD с закрытой системой другого назначения **вне этого проекта и не изменяется**. Репозиторий предназначен исключительно для аудиоплеера.

## Отправная точка

Вместо немедленной разработки собственного движка сначала оценить **Phoniebox** и **One Button Audiobook Player**; для минимальной реализации сравнить `mpd` и `mpv`. Результаты исследования и ограничения: [docs/OSS_RESEARCH.md](docs/OSS_RESEARCH.md).
