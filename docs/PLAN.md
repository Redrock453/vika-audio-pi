# План реализации Vika Audio Pi

Статус: backlog / без автоматического изменения рабочего устройства.

## Этап 0 — инвентаризация и базовый профиль
- [x] Новая ОС Trixie 32-bit на **отдельной** 64-ГБ карте
- [x] Wi-Fi и SSH по ключу с T450
- [x] Найден Bluetooth-контроллер, снята soft-rfkill блокировка
- [x] Наушники определены как HD-610
- [x] Установлен BlueALSA (служба active) — **это не приёмка звука**
- [ ] Зафиксировать фоновые сервисы, память/CPU, температуру
- [ ] Сохранить резервную копию конфигурации без секретов, документировать восстановление

## Этап 1 — проверка аудиомаршрутов
- [ ] Проверить BlueALSA/A2DP и стабильное сопряжение HD-610; прежняя ошибка: `Protocol not available`
- [ ] Сделать одно тестовое MP3-воспроизведение; подтвердить звук на наушниках
- [ ] Проверить аналоговый выход 3,5 мм и поведение при потере Bluetooth
- [ ] Цикл 3 реконнекта и повтор после reboot

## Этап 2 — плеер MVP (P0)
- [ ] Сравнить MPD и mpv по RSS/CPU/startup
- [ ] Локальная библиотека, индексация MP3
- [ ] SQLite bookmarks и recovery после power loss
- [ ] GPIO или USB HID кнопка «play/pause»
- [ ] Systemd service без root; без публичных портов
- [ ] Приёмочные испытания P0 из SPEC.md

## Этап 3 — удобство (P1)
- [ ] Навигация по книге/главам, громкость, таймер сна
- [ ] Объединённые аудиоподсказки TTS/предзаписанные
- [ ] Контент через SSH/USB, безопасная переиндексация
- [ ] Опциональная AVRCP-обработка кнопок гарнитуры

## Этап 4 — голос (P2; независимый эксперимент)
- [ ] Выбрать микрофон (USB/HFP), проверить звук входа на Pi
- [ ] Push-to-talk; фиксированный словарь RU/UK, нет постоянного облака
- [ ] Сравнение PocketSphinx / Vosk small на реальных 512 МБ
- [ ] Замеры false positives, RSS/CPU и контроль доступа
- [ ] Тонкая интеграция с Викой только после отдельной приёмки

## Gates
- Ни один этап не считается завершённым по «пакет установлен».
- Инсталляторы из интернета не исполняются вслепую.
- Никакой прошивки/очистки носителей в рамках этих задач.
- Мерж/деплой крупных изменений — отдельно после тестов и явного согласования.
