# Architecture Decision Record — 2026-11-23

## ADR-001: Separate project, private repository

- Репозиторий: `Redrock453/vika-audio-pi` (private).
- Локальное исполнение на Raspberry Pi, не переносить текущую `bas-ecosystem` и не добавлять LLM.
- Ни секреты Wi-Fi, ни приватные SSH-ключи, ни аудиобиблиотеку в GitHub не загружать.
- Старая родная microSD 32 ГБ — не трогать; используется отдельная 64 ГБ.

## ADR-002: Минимальные компоненты вместо полноразмерного комбайна

- Выбирать реализацию после небольшого теста `mpd` vs `mpv` на 3 A+.
- `BlueZ + BlueALSA` — основной кандидат для headless A2DP вывода.
- `espeak-ng` — простой офлайн TTS для статусных фраз; качество речи оценить отдельно.
- Контроль воспроизведения и состояний детерминированный; локальный Unix socket, не публичный порт.

## ADR-003: Никакого обязательного микрофона в MVP

- Штатный комбинированный 3,5-мм аудио/видео разъём Pi не имеет входа для микрофона.
- Кнопка проводной гарнитуры сама по себе не считывается через этот разъём.
- Реальные варианты входа: USB-аудиокарта с TRRS/микрофоном, USB HID-кнопки, GPIO или подтверждённая поддержка Bluetooth HFP/HSP и AVRCP.
- Проверить совместимость прежде чем выбирать оборудование.
- Голосовое распознавание — отдельный необязательный этап.

## Hardware clarification — 2026-11-23

Пользователь сообщил о **двух разных** гарнитурах: обнаруженные по Bluetooth **HD-610**, и **проводные JBL с кнопкой**. Наименование модели, штекер и наличие микрофона проводных JBL пока не подтверждены. Штатный 3,5-мм выход Raspberry Pi воспроизводит звук, но не считывает кнопку или микрофон гарнитуры. Поддержку кнопки через USB-TRRS адаптер считать экспериментом до проверки конкретного устройства; надёжная альтернатива — GPIO/USB HID кнопка. Не смешивать с AVRCP на Bluetooth-наушниках.

## ADR-004: Offline-first / private-first

- Нет зависимости от телефона, интернета, облака или домашнего сервера для прослушивания.
- Wi-Fi и SSH — только для первичной настройки и загрузки контента.
- Никаких общедоступных портов, телеметрии и сетевой публикации по умолчанию.
- Прерванный Bluetooth не должен ломать локальное состояние и сохранённую позицию.

## ADR-005: MPD как движок детерминированного скелета (staged)

- Дата: 2026-11-23. Для офлайн-скелета выбран **MPD + mpc**, а не собственный
  движок: локальная библиотека, очередь, состояние и UNIX-сокет из коробки.
- Основной выход — аналоговый `plughw:0,0`; Bluetooth-выход закомментирован и
  не считается принятым. Публичный TCP-порт не используется: только UNIX-сокет.
- USB-флешка монтируется **только для чтения** и только внутри библиотеки;
  выбор устройства детерминированный, неоднозначность — отказ.
- Сравнение `mpd` и `mpv` по RSS/CPU на 3 A+ **ещё не выполнено**; `mpv`
  остаётся альтернативой, если MPD не уложится в бюджет памяти.
- Развёртывание staged: пакет в репозитории, установка на Pi требует
  интерактивного sudo (у `vika` нет passwordless sudo), приёмка — только на
  железе по `docs/MPD_DEPLOY.md`.

## Current facts (verified via SSH, 2026-11-23)

- `vika-audio.local` доступен по Wi-Fi, SSH по ключу `vika` с T450 работает.
- ОС — Raspbian GNU/Linux 13 (Trixie), 32-bit, на microSD 64 GB.
- Из `free -h`: ~424 МиБ RAM доступно ядру/пользовательскому пространству; ~116 МиБ использовалось при проверке.
- BlueZ обнаружил устройство `HD-610`, Bluetooth контроллер включён после снятия soft-rfkill.
- В журнале сопряжения была ошибка `a2dp-sink profile connect failed: Protocol not available`.
- `bluez-alsa-utils` 4.3.1-3 установлен; `bluealsa.service` запущена. **Это не подтверждает рабочий звук или устойчивое сопряжение**.
- Плеер, физические кнопки, микрофон, STT, TTS и автозапуск ещё не приняты и не реализованы.

## Explicit non-goals

- Реверс, замена или эксплуатация прежней закрытой системы другого назначения.
- Обход лицензий, аппаратных ключей или ограничений стороннего ПО.
- Собственная LLM и всегда-включённая облачная обработка голоса.
- Общедоступная веб-панель или дистанционное управление извне локальной доверенной сети.

## Unresolved / experimental

1. Подтвердить точную модель и возможности гарнитуры `HD-610` (микрофон и медиакнопки могут отличаться).
2. Проверить автоподключение A2DP после выключения/включения наушников и перезагрузки Pi.
3. Измерить память, CPU и время старта альтернатив `mpd`/`mpv` и готовых проектов.
4. Протестировать пригодность распознавания небольшого русско-/украиноязычного словаря на 512 МБ.
5. Привязку к GPIO/USB без пайки выбрать после инвентаризации доступных кнопок и звуковых адаптеров.
